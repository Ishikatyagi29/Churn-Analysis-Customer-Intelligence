# Churn-Analysis-Customer-Intelligence
# portfolio project - OTT Churn Analytics

*Churn and Revenue Impact*

Built churn pipeline with 20+ KPIs. Found 28.6% churn. Monthly users churned 6.7x more than annual. Identified $73.94 MRR loss and $2,047 CLTV erosion. Proposed contract-migration retention strategy.  

*Risk Scoring & Segmentation*

Created risk model using tenure, plan, escalations. Recommended focusing on Premium annual retention strategy.

*Support Analysis*

Linked support data. Escalations tied to churn. Mapped cancellation drivers: price, competition, content.
